# Werner/Syme 1821 catalog, version 1

110 historical entries, normalized by `npm run werner:import` from checked-in source snapshots.

Names, numbers, families and natural-history references: Nicholas Rougeux's transcription of Patrick Syme's public-domain 1821 edition, linked from https://www.c82.net/werner/.

HEX values: independently verified against Robert Rothenberg's CC0-1.0 `Graphics::ColorNames::Werner` table at revision `854ecaa1997d3cc71b75b3324890ed6815241a77`. The upstream README's copyright/license notice and `dist.ini` declaration are preserved alongside the table. License: https://creativecommons.org/publicdomain/zero/1.0/.

All 110 historical names and values match between sources after normalizing punctuation/case for comparison. Display names retain the spreadsheet's original spelling. No historical entries, names or color values are synthesized. Screen values approximate aged scans, not original pigment measurements.

See `provenance.json` for source URLs, checksums and limitations, and [the curation documentation](../../../../../docs/werner-curation.md) for generation, review and export details. Generated review candidates remain separate from this immutable source catalog. `approved.json` explicitly publishes the curator’s 30 approved combinations (and their 65 referenced colors) into unified Color Explore; its source export is preserved in `upstream/approved-export.json`. Later studio decisions never publish automatically.
